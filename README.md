# Medad — Commerce Partnership OS

**مِداد** is an Arabic-first workspace concept for a product-led commerce partnership: discover candidates, inspect the evidence, model per-order economics, draft transparent partnership proposals, and surface actionable events (`Instant ⚡`).

> Current status: interactive local prototype + deterministic Python unit-economics engine. No live market, supplier, courier, advertising, order, partner, or AI integrations are connected. The sample product ideas and values are illustrative only.

This repository is being initialized with a reviewable prototype and tested economics core. The local preview is `index.html`; the reference engine and tests are under `engine/`.
